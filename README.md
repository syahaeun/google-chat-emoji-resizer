# Google Chat 커스텀 이모티콘 확대 설정 매뉴얼

Google Chat에서 사용하는 커스텀 이모티콘의 표시 크기를 확대하여 더욱 크게 볼 수 있도록 설정하는 방법을 안내합니다.

## 대상

다음 환경에서 사용하시는 분을 대상으로 합니다.

- Google Chat의 커스텀 이모티콘을 더 크게 보고 싶은 분
- PC에서 Chrome 브라우저로 Google Chat을 이용하시는 분

---

## 1. 프로그램 다운로드

1. [릴리즈](https://github.com/syahaeun/google-chat-emoji-resizer/releases) 에서 최신 버전 릴리즈 파일을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 해제합니다.
3. 압축 해제한 폴더는 삭제하지 않고 원하는 위치에 보관합니다.

> **주의:** 확장 프로그램을 사용하는 동안 압축 해제한 폴더가 필요합니다. 폴더를 삭제하거나 이동할 경우 확장 프로그램이 정상적으로 동작하지 않을 수 있습니다.

---

## 2. Chrome 확장 프로그램 관리 화면 열기

Chrome 브라우저 우측 상단의 다음 순서로 이동합니다.

**[⋮] → [확장 프로그램] → [확장 프로그램 관리]**

또는 Chrome 주소창에 다음 주소를 입력하여 바로 이동할 수 있습니다.

```text
chrome://extensions/
```

---

## 3. 개발자 모드 활성화

확장 프로그램 관리 화면의 **우측 상단에 있는 [개발자 모드]**를 켭니다.

개발자 모드를 활성화하면 확장 프로그램을 직접 설치할 수 있는 메뉴가 표시됩니다.

---

## 4. 압축 해제된 확장 프로그램 로드

1. 화면 좌측 상단의 **[압축해제된 확장 프로그램 로드]**를 클릭합니다.
2. `1. 프로그램 다운로드` 단계에서 압축 해제한 폴더를 선택합니다.
3. **[폴더 선택]**을 클릭하여 확장 프로그램을 등록합니다.

> **중요:** ZIP 파일 자체가 아닌 **압축 해제된 폴더**를 선택해야 합니다.

정상적으로 등록되었다면 확장 프로그램 관리 화면에서 다음 프로그램을 확인할 수 있습니다.

**Google Chat Custom Emoji Enlarger**

---

## 5. 확장 프로그램 사용 설정

확장 프로그램 관리 화면에서 등록된 **Google Chat Custom Emoji Enlarger**를 확인합니다.

프로그램의 **사용 설정 스위치**를 켭니다.

확장 프로그램이 활성화되면 Google Chat에서 커스텀 이모티콘 확대 기능을 사용할 수 있습니다.

---

## 6. 이모티콘 확대 적용 확인

1. Google Chat 화면으로 이동합니다.
2. 페이지를 새로고침합니다.
3. 채팅창에서 커스텀 이모티콘이 확대되어 표시되는지 확인합니다.

확장 프로그램에서 **원하는 확대 비율을 선택하여 사용할 수 있습니다.**

설정한 확대 비율에 따라 커스텀 이모티콘의 표시 크기가 달라집니다.

---

## 참고 사항

- 해당 설정은 **확장 프로그램을 설치한 개인 PC의 Chrome 브라우저에서만 적용**됩니다.
- 상대방의 Google Chat 화면에 표시되는 이모티콘 크기는 변경되지 않습니다.
- 확대 기능을 해제하려면 Chrome의 **확장 프로그램 관리** 화면에서 해당 프로그램의 사용 설정 스위치를 끄면 됩니다.
- 확장 프로그램을 사용하는 동안 **압축 해제한 폴더를 삭제하거나 이동하지 않는 것을 권장**합니다.
